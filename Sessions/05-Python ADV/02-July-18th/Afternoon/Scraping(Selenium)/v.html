فریمورک جنگو ( پایتون ) را از کجا یاد بگیرم

سلام

من خیلی توی گروه های مختلف میبینم که افراد به دنبال یادگیری فریمورک جنگو هستند و اکثرا هم سردرگم هستند که دنبال کدام دوره ی آموزشی بروند آیا هزینه کنند یا از دوره های رایگان استفاده کنند؟

اول اینکه به زبون ساده بگم جنگو چیه ؟

جنگو چیست ؟

جنگو یکی از فریمورک های توسعه وب هست که در backend استفاده میشود. اگر اسم لاراول یا کدایگنایتر را شنیده باشید جنگو هم دقیقا مثل آنهاست ولی تفاوت جنگو با آنها این است که آن فریمورک ها با زبان برنامه نویسی PHP هستند ولی جنگو با زبان Python هست.


با فریمورک جنگو میتوانید سایت های بسیار پرسرعت و ایمن بسازید و به نظرم برای پروژه های درست حسابی و قوی بهتره از جنگو استفاده شه

یه چندتا سوال که همیشه درباره ی فریمورک جنگو شنیدم رو جواب میدم سریع جواب میدم حوصله توضیح زیاد ندارم چون چیزهای عیان و آشکاری هستن چیز عیان چه حاجب به بیان ؟

  • آیا یادگیری جنگو سخت است ؟ اگه پایتون بلدی نه اگه پایتون بلد نیستی آره
  • پیش نیاز جنگو چیه ؟ بلد بودن زبان پایتون
  • با فریمورک جنگو چه نوع سایت هایی میشه ساخت ؟ هر نوع سایتی ولی بیشتر سایت های که ترافیک خوبی دارن
  • فریمورک جنگو برای کدام قسمت وب استفاده میشود ؟ برای سمت سرور ( بک اند یا backend )

خب من به چندین سوال عمومی جواب دادم و شما تقریبا الان میدونید که Django چیه

خب برای یادگیری این فریمورک زیبا شما میتونید از دوره ی آموزش زیر شروع کنید که استاد سام نیکزاد مدرس آن هستند و واقعا تدریس عالی دارند ایشان استاد بنده بودن و من پایتون - فریمورک فلسک پایتون و فریمورک جنگوو را یاد گرفتم و حتما توصیه میکنم از دوره های ایشان استفاده کنید :
